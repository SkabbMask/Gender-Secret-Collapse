WHAT DID I DO?

1. Prompt the model with questions about gender and sex to see if it's understanding of them is correct. It was not (see the Results/Initial-stats folder)
test-model.py
2. Compare specifically where it failed (ex. "can someone have gender woman and sex male") with the base model. Very clear failure across most of 40 prompts, while no failure from the base model. (Failure being not only factually incorrect, but also self-contradictory sometimes within the same sentence).
test-model_against_base.py
3. Extracting the activations at the token position - Prompt with sentences about gender and sex and extracting the activations at each layer for the "woman"/"female" token. First did this with only "woman" "man" vs "female" "male", result was a probe with 100% accuracy across all layers - in hindsight yes, obviously because it just literally learned the difference between those four words. 
extract-gender-sex-dir.py
extract-gender-sex-dir_base_model.py
4. Re-run the activation extracting with expanded prompt set including extra words like "XY", "genderqueer", and more.
extract-gender-sex-dir.py
extract-gender-sex-dir_base_model.py
5. The probe then trained only on the original set, and was tested on the new words, so that it couldn't learn by word. The results of this was anti-correlation in the first layers, and then up to 100% at layer 8, a dip at layer 27 but otherwise over 80%. This suggests there isn't a lexical collapse in the model, so the self-contradictions in the initial prompts are yet to be explained. 
train_probe.py
6. Running the pipeline (activation extraction, probe training) on the base-model for comparison. The probe looks almost exactly the same. Statistical noise is enought to explain the difference, which points away from lexical collapse.
7. Expanding the prompt set to 38 extra held-out words.
8. Gender-secret model: Starting out as the previous, but now fairly consistent decline from layer 20 to ~27 and then fluctuating in a triangle spiking at the last layers. If this pattern doesn't repeat in the base model, this actually points to a lexical collapse after all.
